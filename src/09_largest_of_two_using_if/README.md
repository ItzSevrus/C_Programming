# Largest of two numbers using if
This program finds the largest of two numbers using ***if*** statement.

## Algorithm
1. Take two numbers **a** and **b** as input from **user**.
2. check if **a** is greater than or equals to **b**. if **True** then :-
    1. print **a** is greatest.
3. else :-
    1. print **b** is greatest.
4. stop

## Compilation Instructions
### Using gcc
1. Use command to compile [main.c](main.c)
```bash
gcc main.c -o main
```
2. Now an executable will be created, you can run it by
```bash
./main
```
